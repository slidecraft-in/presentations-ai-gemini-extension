# Presentations.AI

This extension connects the `presentations-ai` MCP server, which creates designed slide decks
and manages the ones already in the user's Presentations.AI workspace.

Two bundled skills hold the step-by-step workflows. Activate the one that fits the request:

- `create-presentation`: a new deck from a topic, the user's text, or a reviewed outline,
  delivered as a PowerPoint, PDF, or slide images.
- `manage-presentations`: find, inspect, rename, move, share, download again, or delete a deck
  the user already has.

Decks and outlines spend credits from the user's workspace. Create one only when the user asks
for it, and share or delete a deck only on request.
